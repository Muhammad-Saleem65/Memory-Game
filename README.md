Pokemon Memory Game is a React-based browser game built to practice state management, API fetching, and game logic in a real-world app. The project focuses on creating a fun and interactive memory challenge where players click different Pokémon cards without repeating the same one.

What I implemented
Built the full game UI using React
Created a card-based memory game layout
Used React state to track:
current score
best score
clicked Pokémon IDs
Implemented score logic so the player loses when they click a Pokémon twice in the same round
Shuffled Pokémon cards after each click to keep the game unpredictable
Fetched Pokémon data from the Pokémon API using async/await
Displayed each Pokémon image and name in the game board
Added a responsive, styled layout with modern gradients and card styling
